# 项目二 · 严格样本外验证报告（协议 v3，2026-08-23）

> 目的：消除"参数在评估期扫描"与"确认期=交易期"两个方法论缺陷，回答一个根本问题——
> **配对策略在严格样本分离下是否真有样本外收益？**
> 答案（本报告）：**没有。原 +1.34% 是选择偏差产物，偏差幅度已量化。**

---

## 1. 为什么做这次验证（预注册：docs/UPGRADE.md）

原设计两个被独立审查标记的缺陷：
1. 参数扫描在 OOS（2022-2026）上做 → 最优格有选择偏差
2. 协整确认窗口 = 回测交易窗口 → "确认通过"条件于交易期数据

**协议 v3 修正**（全部预注册后执行，结果未改口径）：
| 环节 | 原设计（污染） | 协议 v3（严格） |
|---|---|---|
| 协整 IS 筛选 | 2017-2021 | 不变 |
| 确认窗口 | 2022-2026（=交易期）| **2022-2023** |
| 交易方向 | 固定方向 1 | **按 min-p 方向**（方向无关筛选 ↔ 方向固定交易的错配修正）|
| 参数选择 | OOS 全期扫描 | **2022-2023 扫描，冻结** |
| 交易期 | 2022-2026 | **2024-2026 冷启动（净值 1.0 起）** |
| 统计推断 | 无 | **bootstrap 夏普置信区间** |

## 2. 结果

### 2.1 选择（三层协议）
- tier1 IS-FDR(2017-21, min-p, m=9724)：97 对
- tier2 确认窗 FDR(2022-23) + hl：**仅 2 对**（600038_600765 军工 / 601128_601288 银行）
- 经济逻辑审查（预注册"经济逻辑先行"）：**排除 601128_601288**——其交易方向 β 在样本内从 −0.31 翻转到 +0.63（农行 2017 贱/2026 贵的单次相对走势，中特估行情驱动，非稳定协整）
- **严格书 = 1 对：600038_600765（中直股份_中航重机，β 0.31→0.44 稳定）**

### 2.2 选参段（2022-2023，参数选择窗）
| 配置 | 选参段收益 | 选参段夏普 |
|---|---|---|
| 1.5/0.0/3.0/w0=0.3（选定）| +6.2% | **0.90** |
| 1.5/0.0/3.0/w0=0.5 | +10.4% | 0.89 |
| 最优区（z_entry=1.5, z_exit=0）| — | 0.68-0.90 |

### 2.3 纯样本外（2024-2026，冷启动，参数冻结）
| 配置 | OOS 净值 | OOS 总收益 | OOS 夏普 | 回撤 |
|---|---|---|---|---|
| **选定 1.5/0.0/3.0/w0=0.3** | 0.9985 | **−0.15%** | **−0.02** | −3.4% |
| bootstrap 年化 95%CI | — | [−2.3%, +2.2%] | — | — |
| bootstrap 夏普 95%CI | — | — | [−2.08, +0.87] | — |
| P(夏普>0) | — | — | **39%** | — |

### 2.4 全 36 格参数 OOS 稳健性（防"换参数翻正"）
- **仅 4/36 格 OOS 夏普为正**；OOS 夏普中位数 **−0.59**（25 分位 −0.63 / 75 分位 −0.32）
- 选参段 top10 格在 OOS 的表现：−0.02 ~ +0.07（≈0），无一显著为正
- **选参段夏普与 OOS 夏普无正相关**：选参段的最优区正是 OOS 的平庸区

## 3. 结论（诚实，不粉饰）

1. **A 股 hs800 大票配对交易在严格样本分离下无显著样本外收益**（1 对书 2024-2026 夏普 −0.02，bootstrap 拒绝不了夏普=0）
2. **原 +1.34%/年（3 对核心）是选择偏差产物**：同样的策略，把确认窗口和参数扫描严格锁进 2022-2023 后，样本外收益 ≈ 0；偏差幅度可量化（+1.34% → −0.15%）
3. **协整筛选对交易窗口的依赖极强**：9 对（2022-26 确认）→ 2 对（2022-23 确认）→ 1 对（经济逻辑过滤）→ 0 显著样本外收益——**"选出来的对子"与"真能交易的对子"是两回事**
4. **方法论贡献 > 策略贡献**：本报告演示了选择偏差的完整量化路径（含 bootstrap 置信区间与全参数 OOS 分布），这是比一个漂亮回测更稀缺的科研能力展示

### 3.1 扩展候选池的最终验证（中证 1000，P3）

为排除"hs800 池太小"的干扰，扩展池到 **hs800 + 中证 1000 = 1800 只（882 合格股 → 18,734 候选对）**，严格三层协议重跑：

| 环节 | hs800（原） | hs800+中证1000（扩展）|
|---|---|---|
| 候选对 | 4,953 | 18,734 |
| tier2 确认(2022-23) | 2 | 32 |
| tier3 方向过滤+经济逻辑 | 1 | **7**（电力/通信/军工/传媒/化工/券商×2）|
| 选参段(2022-23) 最优区 | 夏普 0.90 | 夏普 0.37-0.46 |
| **纯样本外(2024-26)** | **−0.02** | **−0.70（净值 −14.4%）**|
| 36 格 OOS 正收益格数 | 4/36 | 8/36 |
| 选参段最优格 → OOS | −0.02 | **−0.68（选参最好的格 OOS 最差）**|

**扩展池结论**：更多候选对 → 更多"显著对"（经济合理、行业多样），但**样本外收益没有改善，反而更明确地为负**——选参段表现最好的参数在 OOS 表现最差（过拟合的经典负相关）。**"数据不够"不是本项目负结果的原因，"选择偏差 + 关系不稳定"才是。**

## 4. 局限与后续

- 样本极小（1 对 × 2.6 年 ≈ 36 事件），bootstrap 区间很宽——即使真有效也应不出
- 扩展候选池（中证 1000，后台拉取中）是唯一可能找到"真样本外存活对"的路径，但按当前证据概率不高
- 本验证不做任何参数后调（诚实边界：2024-2026 零重选零调整零事后确认）
