# A 股配对交易 / 统计套利（Pairs Trading）

> 研究项目（简历项目）：卡尔曼时变 β 的统计套利策略，样本外 2022-2026。
> 完整报告：`reports/STRATEGY_REPORT.md`；预注册口径：`docs/`。

## 核心结论（诚实摘要）

1. **A 股大票静态对数协整稀有且不稳定**：4862 对同行业液体对，IS 显著仅 16 对；静态 β 样本外 0 对存活（β 漂移 53-176%）→ **卡尔曼时变 β 是必需**
2. **方向 1 显著性 = 质量过滤器**：方向 1 显著的 3 对全部盈利；方向 2 侥幸对盈亏混杂拖死全书（9 对书 162 格参数全负）
3. **成本是决定性约束**：经典 z-score 配对毛利 2.4%/年 < 双边成本 5.5%/年
4. **终版（3 对核心 + 严格入场 2.5σ）**：净 +1.34%/年、夏普 0.29、回撤 -9.9%（融券费 0-10% 假设稳健）；接近盈亏平衡，不建议实盘
