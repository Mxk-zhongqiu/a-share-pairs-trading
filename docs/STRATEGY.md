## 2. 仓位与方向（写死）

- 方向：`z > +entry` → A 相对贵 → **空 A 多 B**；`z < −entry` → 反向
- 仓位：β-对冲等毛利 `gross = w0` 每对——
  `w_A = w0/(1+|β̂|)`，`w_B = w0·|β̂|/(1+|β̂|)`（入场时卡尔曼 β̂，截断 [0.25, 2.5]）
- 无杠杆：`n_active × w0 ≤ 1` → w0=0.3、最多 3 对同时持仓（毛利 ≤ 0.9，现金 ≥ 0.1 备费用）
- 多对共享同一股票时权重叠加（如 601881 同时出现在 2 对）——引擎按 per-stock 汇总

## 3. 退出与风控（写死）

| 规则 | 条件 | 说明 |
|---|---|---|
| 回归平仓 | `|z| ≤ z_exit` | 价差回到均值 |
| 止损 | `|z| ≥ z_stop` | 价差继续发散（关系破裂先兆）|
| **止损冷却（v2 修订）** | 止损后 stop_cool=10 日内不重进 | 止损时价差仍在发散，立即重进=接飞刀（实测 stop 交易胜率 12.9%）；等 z 回到 <entry 再评估 |
| 超时 | 持有 ≥ max_hold 日 | 资金占用效率 |
| **关系破裂** | 每 5 日滚动 250 日卡尔曼残差 EG-ADF，p > 0.05 | 平仓 + 暂停 20 日（交接文档 §3）|

**v2 修订记录（2026-08-23，机制驱动）**：
① **止损冷却**：首轮回测 62 笔止损中 87% 亏损（止损后 z 仍超 entry，策略立即重进继续发散）；
② **持仓期不每日再平衡**：首轮回测每日输出目标 → 引擎每日按权重再平衡，实测 6.2%/日换手
（累计 145 倍），佣金+滑点+印花 ≈23% NAV 损耗 + 融券费 29.6%——信号 P&L 为正但被成本拖垮。
修复：仅在状态跳变日输出目标（持仓期固定股数），换手降到开平仓事件本身。
