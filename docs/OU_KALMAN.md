## 2. OU 建模（静态基准）

对每对 IS 价差 `s_t = la_t − β̂·lb_t − α̂`（β̂,α̂ = IS 全样本 EG 估计）:

- 离散 AR(1): `s_{t+1} = a + b·s_t + ε`
- 参数: `θ = −ln(b)`（均值回归速度）、`μ = a/(1−b)`（长期均值）、
  `σ_ε = std(ε)`、长期波动 `σ_ss = σ_ε/√(1−b²)`
- 输出: 每对的 OU 参数表（θ/μ/σ_ss/hl），供静态 z-score 信号对照

## 3. 卡尔曼时变估计（主模型）

**状态空间模型**（时变 β，random walk 状态转移）:
```
状态:   x_t = [α_t, β_t]ᵀ        x_{t+1} = x_t + η_t,  η ~ N(0, Q)
观测:   la_t = α_t + β_t·lb_t + ε_t,  ε ~ N(0, R)
观测矩阵 H_t = [1, lb_t]
```

**参数标定（全部只用 IS 数据，防未来函数）**:
| 参数 | 标定方法（IS） |
|---|---|
| R = σ_ε² | IS EG 残差方差 |
| Q = diag(q_α, q_β) | 网格搜索（IS 内滚动预测误差最小）或 q_β = 0.01·R 规则，**预注册两种并报告选择** |
| 初值 x_0, P_0 | IS EG 估计 β̂ 及协方差 |

**因果性硬约束（逐条核对）**:
1. 滤波从 IS 起点开始**前向递推**，t 时刻状态只用 ≤t 观测（KF 天然因果）
2. **禁止**全样本/未来数据标定 Q、R（标定窗口 = IS）
3. **禁止**使用 Kalman smoother（双向平滑）——只用 filtered estimate
4. 交易期开始后参数**冻结**（Q、R 不再重标），只让 β 随时间漂移

**信号定义**:
- 预测残差（可交易价差）: `e_t = la_t − H_t·x̂_{t|t-1}`（t 收盘已知，t+1 交易）
- z-score: `z_t = (e_t − μ_e,roll)/σ_e,roll`，滚动窗口 60 日（预注册，IS 内验证窗口选择）

## 4. 信号规则（预注册，p3c 执行，参数扫描 P9）

| 参数 | 默认值 | 扫描范围 |
|---|---|---|
| 开仓阈值 z_entry | 2.0 | {1.5, 2.0, 2.5} |
| 平仓阈值 z_exit | 0.0 | {0.0, 0.5} |
| 止损阈值 z_stop | 3.5 | {3.0, 3.5, 4.0} |
| 最大持有天数 | 60 | {40, 60, 90} |

方向约定：`z_t > +z_entry` → A 相对贵 → **做空 A / 做多 B**（赌价差回归）；
`z_t < −z_entry` → 反向。`|z_t| ≤ z_exit` 平仓；`|z_t| > z_stop` 止损（关系破裂风控）。
