## 1. 池子定义（写死后不再改）

| 维度 | 规则 | 理由 / 来源 |
|---|---|---|
| 基础池 | hs800 = 沪深300 + 中证500 并集（800 只） | 复用项目一已 QA 数据；并集缓解幸存者偏差 |
| 时间范围 | 2017-01-01 ~ 2026-08-21（2340 交易日） | 数据已就绪；覆盖 2018 熊市 |
| 行业归属 | 申万一级（31 个），**当前**成分归属 | 经济逻辑先行（同行业才谈得上协整）；当前归属=快照，幸存者偏差口径与项目一一致，报告披露 |

| 剔除 | ① ST/退市风险标记（st_list 命中）② 数据缺失 > 40 交易日（长期停牌）③ 区间内无完整价格 | 价格口径必须齐整，配对对齐才有意义 |
| 配对空间 | 同申万一级行业内两两组合；**行业内合格股数 ≥ 3 才纳入** | 2 只的行业退化成"必然配对"，无筛选意义；≥3 才有"选对"的信息量 |
| 候选对输出 | 全量两两组合（不预先挑"看着协整"的对） | 预注册：筛选留到 p3 协整检验阶段，按统计量排序 |

## 2. 为什么这样定（决策记录）

1. **行业粒度选申万一级而非巨潮末级**：巨潮末级 591 类 ≈ 每只股票一个类，无法形成"同类多只"的配对空间；申万一级 31 类粒度适中（银行/券商/保险/煤炭/钢铁/白酒/医药…），且 `ak.index_component_sw` 接口实测可用。
2. **流动性门槛 1 亿**：项目一 P7 实测——85% 持仓日成交额 <1 亿时回测 +1636% 是纸面幻觉。配对交易双边换手更高，门槛只升不降。
3. **行业 ≥3 只**：行业内对子数 = C(n,2)。n=2 → 1 对（无选择余地）；n≥3 才有候选多样性，也才能对"同行业哪些对真协整"做多重检验修正。

## 3. 预注册的统计口径（p3 阶段执行，先记于此）

- 协整检验：Engle-Granger（ADF 残差）为主，Johansen 为辅；α 水平 0.05 → Bonferroni 修正（m=候选对数）
- 信号期 vs 检验期分离：先用 2017-2021 估计协整/参数，2022-2026 样本外验证（防未来函数 + 检验"关系是否稳定"）
- 关系稳定性：样本外滚动再检验（协整在样本外是否还在）
