## 2. 检验口径（写死）

1. **Engle-Granger 双向**：`la = α + β·lb + ε` 与 `lb = α' + β'·la + ε'` 都跑
   （有限样本下 EG 不对称，双向都测，取每对最小 ADF p —— 预注册）
2. **ADF**：残差 ADF，含常数项、无趋势，滞后阶 AIC 自动选择（`statsmodels adfuller`）
3. **多重检验**：测试总数 **m = 2 × 候选对数**（双向各算一次）
   - Bonferroni：α_B = 0.05 / m
   - 同时报 Benjamini-Hochberg FDR 阈值（p 排序后 0.05·i/m）
4. **半衰期**：IS 价差序列 `s_t = la − β̂·lb − α̂` 做 AR(1) `s_t = ρ·s_{t-1} + η`，
   `hl = −ln2 / ln|ρ|`（单位：交易日）
5. **IS 通过标准**（两条件同时满足）：
   - 最小 ADF p < α_B（Bonferroni）
   - **1 ≤ hl ≤ 90**（均值回归太慢 = 资金占用无效率，太快的对子多为噪声/无套利空间）
6. **OOS 稳定性**（对 IS 通过的对，确认性检验，m = IS 通过对数）：
   - 用 IS 的 (α̂, β̂) 直接算 OOS 价差 → 再回归出 OOS 残差做 ADF
   - 同时重估 OOS 半衰期
   - 标准：OOS ADF p < 0.05（FDR 修正后）且 OOS 半衰期仍在 [1, 120]（放宽，因为 β 可能漂移）

## 3. 为什么这样定

1. **双向 EG**：协整存在性不依赖方向，但有限样本两条回归结论可能不同；取 min p 更全，代价是 m 翻倍（Bonferroni 更严）——预注册接受这个代价。
2. **半衰期进入筛选**：ADF 显著 ≠ 可交易（显著但半年才回归的配对没意义）；hl∈[1,90] 是文献常用可行区间。
3. **IS/OOS 分离**：卡尔曼/OU 参数只用 IS 估计，OOS 纯验证——交接文档 §3"卡尔曼未来函数"防线的数据侧。
4. **α_B 极严是故意的**：m≈9900 → α_B≈5e-6。真协整的银行/券商对子 ADF p 通常 < 1e-10，不会误杀；筛掉的是假阳性。

## 5. 口径修订 v2（2026-08-23，机制驱动，预注册）

**修订理由**（不是凑结果，是诊断驱动的口径修正）：
静态 β 的 OOS 确认把"β 漂移"误判成"关系破裂"——诊断显示 6/16 对在 OOS 重估 β 后
重新显著。而交易阶段的卡尔曼本来就是**时变 β**，所以 OOS 确认必须与交易机制一致
（允许 β 漂移），否则筛选结果与实现机制自相矛盾。

| 项 | v1（作废） | v2（现行） |
|---|---|---|
| IS 筛选 | Bonferroni m=2×对 + hl∈[1,90] | 不变 |
| OOS 确认 | 用 IS 静态 (α,β) 算 OOS 价差 ADF | **OOS 重估 (α,β)** → OOS 残差 ADF（FDR 修正）+ hl_oos∈[1,120] |
| 输出 | pass_oos | pass_oos（v2 口径）+ 保留静态结果对照（诚实披露）|

诚实披露：v2 允许 β 漂移后，OOS 显著性反映的是"关系仍存在"（可被卡尔曼跟踪），
不是"静态对冲比率仍有效"；后者在 v1 已证伪（0/16）。两套数字都会进报告。
